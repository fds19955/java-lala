7 关键笔记：

  第二： application.yml文件有两个版本，本地版本和阿里云docker版本，看情况弄

  第好几： 备份数据库
  windows里面数据库全弄出去 C:\Users\Administrator>mysqldump -u root -p --databases article_db --add-drop-database --set-gtid-purged=OFF --single-transaction --default-character-set=utf8mb4 > article_db.sql
         输入密码，然后备份了数据库，准备迁移。生成位置在：C:\Users\Administrator\article_db.sql

8 关键命令：
# 查看服务状态
docker compose ps

# 查看实时日志
docker compose logs -f backend-app

# 停止所有服务
docker compose down

# 重启所有服务（保留数据）
docker compose restart

# 更新代码后重新构建
docker compose down
docker compose up -d --build

# 使用-f指定配置文件，查看本Compose项目下的容器状态
docker compose -f docker-compose-ci.yml ps
