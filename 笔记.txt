1. GitLab SSH连接端口问题
问题：SSH连接测试成功，但推送代码时提示Permission denied (publickey,password)
原因：GitLab的SSH端口被设置为2224，而不是默认的22，远程仓库URL没有指定端口

解决
git remote set-url origin ssh://git@49.233.185.174:2224/fds/java-lala.git

2. Git推送分支不存在问题
问题：推送代码时提示src refspec feature/initial-commit does not match any
原因：本地分支feature/initial-commit不存在，或者没有提交任何代码
解决方法：先创建并切换到功能分支，添加并提交代码，再推送

解决
git checkout -b feature/initial-commit
git add .
git commit -m "Initial commit: 提交项目初始代码"
git push -u origin feature/initial-commit
